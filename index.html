How to use VMA GPA Calculator

Track courses manually or import them from PowerSchool.

1. Add and edit courses
Use Add course to enter a course, percentage, and credits. Changes are saved locally.

2. Import from PowerSchool
Paste your PowerSchool grades, then select Detect Courses. Credits are matched from the 2026–2027 course database.

3. Check credits
Review the preview. Unmatched credits are highlighted and can be entered manually.

4. Choose how to import
When courses already exist, choose whether to keep them or overwrite them.
